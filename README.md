# Churn-Analysis-python-project-on-large-data
Customer churn analysis on subscription data using Python, Pandas &amp; Seaborn — data cleaning, EDA, churn drivers, and revenue-at-risk insights.
# Customer Churn Analysis

This project analyzes customer churn for a subscription-based business using data pulled from a SQLite database across three tables — customer, subscription, and support records. It covers data cleaning, merging, feature engineering (churn flag, churn risk, tenure), exploratory data analysis, and visualization to uncover key drivers behind customer churn and quantify revenue impact.

**Key questions explored:**
- What is the overall churn rate, and which customer segments churn the most?
- Does plan type, acquisition channel, or region affect churn?
- How much revenue is at risk due to churned customers?
- Do customer complaints/escalations predict churn?

**Tools used:** Python, Pandas, NumPy, Matplotlib, Seaborn, SQLite
